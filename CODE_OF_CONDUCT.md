# Code of conduct

CascadeLens follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be respectful, specific, and evidence-aware. Harassment, discrimination, doxxing, credential disclosure, and publication of proprietary or restricted data are not accepted.

Report conduct concerns privately to the repository maintainer. Security issues must use GitHub private vulnerability reporting as described in `SECURITY.md`.
