# CascadeLens reference-case library

This directory contains 12 executable reference cases. They exercise the complete analysis and packaging pipeline across diverse domains. They are not demonstrations of empirical accuracy: all 12 are currently scenario-only and zero are historically scored.

Each case includes an assumption register, context citation, sealed graph, ShockScript, model card, cascade bounds, intervention analysis, observability output, benchmark status, verified RiskPack, and rebuild command.
